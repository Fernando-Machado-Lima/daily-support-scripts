# Daily Support Scripts

Coleção de scripts para automação de tarefas e facilitação de suporte técnico via Tampermonkey.

## 📜 Scripts Incluídos

1. **Matrix Go Quick Replies** (`matrix-go-quick-replies.user.js`)
   - Painel lateral com botões de respostas rápidas personalizáveis para o sistema Matrix Go.

2. **Login Helper** (`login-helper.user.js`)
   - Menu lateral para detecção de telas de login (ZTE / Multilaser / Huawei) e preenchimento rápido de perfis de teste.

## 🚀 Como Instalar
1. Instale a extensão **Tampermonkey** no seu navegador.
2. Clique no arquivo `.user.js` desejado neste repositório.
3. Clique no botão **Raw** para abrir o script e confirmar a instalação no Tampermonkey.
